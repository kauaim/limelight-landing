# Limelight Energy landing page

Static site for limelightenergy.com, hosted on GitHub Pages. No build step.

## Set the Formspree ID

1. Create a form at formspree.io and copy its ID (the part after `/f/` in the endpoint URL).
2. In `index.html`, find the `REPLACE BEFORE LAUNCH` comment and replace `YOUR_FORM_ID` in the form's `action` on the next line.
3. Commit and push.

The form will not deliver messages until this is done.
